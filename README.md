## About

OSP2-BE is an extended edition of [OSP2](https://github.com/snems/OSP2) — an attempt to recover the old OSP mod source code and improve upon it, based on vanilla Q3 and OSP files analysis.

The source code is open: **[scoqx/osp2-be](https://github.com/scoqx/osp2-be)**.

## Installation

1. Download the latest [QVM pack](https://github.com/scoqx/osp2-be/releases/latest/download/zz-osp-pak8be.pk3) (or the native [Windows `.dll`](https://github.com/scoqx/osp2-be/releases/latest/download/osp2-be-windows.zip) / [Linux `.so`](https://github.com/scoqx/osp2-be/releases/latest/download/osp2-be-linux.tar.gz)).
2. Get the original [OSP 1.03](https://www.moddb.com/mods/osp/downloads/osp-mod-103a-full) or just its [resources](https://osp2.q3a.space/assets/zz-osp-oldres.pk3).
3. Put everything into the `osp` folder of your Quake 3 Arena directory.

Changelog, commands, configs and tools are on the site: **[osp2.q3a.space](https://osp2.q3a.space/)**.
